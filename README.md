# RootRun

Strong roots, strong stride.

An app that suggests a simple strength plan to runners.

## First audience

- Beginner runners training for a first 5K or 10K
- Two sessions per week, 15 to 30 minutes each
- Little or no equipment

## Status

Step 0: planning. No app code yet.

## Planned structure

- `docs/` for plans, exercise cues, and reviewer notes
- `rules/` for the plan-generation rules (intake in, schedule out)
- `app/` for the web app

## Notes

- All training rules are drafts until a qualified coach or physiotherapist reviews them.
- This app does not give medical advice.
